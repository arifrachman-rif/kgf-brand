# KGF Brand Toolkit — Public

Panduan brand **PT Klumbayan Gold Farm** untuk tim, mitra, desainer, dan percetakan.

**Buka brand book:** https://arifrachman-rif.github.io/kgf-brand/

| File | Fungsi |
|:---|:---|
| `index.html` | **Brand book interaktif** — warna, tipografi, logo, voice, klaim, template, design tokens. Buka langsung di browser. |
| `kgf-brand-toolkit.md` | Versi teks cepat. |
| `mockups.html` | Mockup cetak: kartu nama (COO & CEO), banner, standing banner, flyer A5. Konsep, bukan file cetak. |

## Aset (unduh logo)

Semua logo resmi (4 varian: Full Color, Black, White, Gold) tersedia di
[Google Drive — KGF Brand Assets](https://drive.google.com/drive/folders/1l1ijNdMeVFeVhaQygRRE_fk_-u37NjOz).
Aset tambahan (foto operasional, logo partner dalam format lain) diminta ke tim.

## Aturan cepat

1. **Klaim** — patuhi tabel di brand book. Angka wajib: **1.250** petani, gudang **400 ton**, ekspor **Eropa**.
2. **Tanpa gambar AI** — foto operasional asli saja.
3. Logo dari 4 varian resmi; untuk cetak besar minta re-export vektor ke tim.
4. Detail angka bisnis (harga, kontrak) hanya melalui tim KGF.
